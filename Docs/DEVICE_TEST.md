# 아이폰 테스트 체크리스트

시뮬레이터에서는 마이크 소리가 들어오지 않고 VoiceOver·알림·음성 메모도 실제와 다르다. 그래서 아이폰에서만 확인할 수 있는 것을 화면 순서대로 모았다 (PROGRESS.md의 **(직접)** 항목, 2026-10-25 기준).

- **본 순서는 약 35분**이다. 며칠이 걸리거나 정한 시간을 기다려야 하는 항목은 맨 아래 **[따로: 시간이 걸리는 항목](#따로-시간이-걸리는-항목)**에 모았다.
- 항목마다 **어떻게**(할 일) / **정상**(이렇게 보이면 통과) / **이상하면 적을 것** 세 줄이다. 정상이면 체크만 하고, 이상하면 번호와 함께 적는다 (맨 아래 [결과 적는 법](#결과-적는-법)).
- 준비: 최신 빌드를 Xcode로 설치(예전 앱은 지우지 말고 덮어 설치), 조용한 곳, 이어폰 없이 스피커, 기기 음량 70% 정도, 음성 메모 앱에 5~10초짜리 녹음 하나("아—"를 길게 낸 것이 좋다).

---

## 0. 맨 먼저 — 실시간 꺾은선이 실제 목소리로 그려지는가 (2분)
이것이 앱의 기본이다. 안 되면 나머지는 멈추고 이것만 적어 와도 된다.

- [ ] **0-1. 실시간 꺾은선**
  - 어떻게: 앱을 켜고 [높이] 탭 → ‘반복 루프 재생’ → "아—"를 3초쯤 낸 뒤, 문장 카드를 평소처럼 한 번 읽는다. (처음 켤 때 마이크 권한 창이 뜨면 허용하고, ‘내 목소리 재기’ 화면이 뜨면 ‘나중에’로 닫는다 — 2-1을 위해 떴는지 기억해 둔다)
  - 정상: 위의 큰 숫자가 Hz로 바뀌고, 그래프 오른쪽 끝(지금)에서 꺾은선이 생겨 왼쪽으로 흘러간다. 목표 범위 안이면 굵은 분홍, 밖이면 가는 회색이다.
  - 이상하면 적을 것: 숫자도 안 바뀌는지 / 숫자는 바뀌는데 선이 없는지 / 선이 자주 끊기는지, 그리고 그때 목소리 크기(작게·보통·크게).

## 1. 설치·이름·아이콘 (3분)

- [ ] **1-1. 덮어 설치해도 저장값이 그대로**
  - 어떻게: 0-1 전에 켠 첫 화면을 떠올리고, [높이]의 목표 범위(‘조정’ 옆 숫자)와 ‘들려줄 길이’, [기록] 탭의 기록을 본다.
  - 정상: 설치 전 값 그대로다 (예전부터 쓰던 180~220 Hz 또는 직접 옮긴 값). 예전 버전에서 설정을 한 번도 바꾼 적 없으면 새로 설치한 것으로 보아 목표 범위 없이 시작할 수 있고, 그때는 재기 화면의 맞추기 스위치가 켜져 있다.
  - 이상하면 적을 것: 무엇이 어떻게 바뀌었는지 (예: 목표 범위 180~220 → 없음, 기록이 비어 있음).
- [ ] **1-2. 홈 화면 이름**
  - 어떻게: 홈 화면에서 앱 아이콘 아래 글자를 본다.
  - 정상: "울림".
  - 이상하면 적을 것: 보이는 이름 (예: VoicePractice).
- [ ] **1-3. 권한 창의 이름**
  - 어떻게: 0-1에서 마이크 권한 창이 떴다면 그 문장을 떠올린다 (이미 허용해 둔 기기면 안 뜨니 건너뛴다).
  - 정상: "‘울림’이(가) 마이크에 접근하려고 합니다"처럼 울림으로 나온다.
  - 이상하면 적을 것: 권한 창에 나온 앱 이름.
- [ ] **1-4. 아이콘**
  - 어떻게: 홈 화면, 설정 앱의 앱 목록, (7-2에서) 알림 배너의 아이콘을 본다. 홈 화면을 길게 누르기 → 편집 → 사용자화에서 ‘어둡게’와 ‘색조’로도 바꿔 본다.
  - 정상: 원 무늬와 파형이 알아볼 만하다. 어둡게·색조에서도 무엇인지 알 수 있다.
  - 이상하면 적을 것: 어디서(홈·설정·알림, 어둡게·색조) 어떻게 보였는지 (흐림, 잘림, 배경이 이상함). 캡처가 있으면 좋다.

## 2. 처음 실행 — 내 목소리 재기 (5분)

- [ ] **2-1. 처음 한 번만 뜨는 재기 화면**
  - 어떻게: 0-1에서 ‘내 목소리 재기’가 떴는지 떠올린다. 떴다면 앱을 완전히 끄고(위로 쓸어 올려 닫기) 다시 켠다. 예전에 이미 쟀다면 처음부터 안 뜨는 것이 정상이니 건너뛴다.
  - 정상: 처음 한 번만 뜨고, ‘나중에’로 닫은 뒤 다시 켜면 뜨지 않는다.
  - 이상하면 적을 것: 다시 켤 때마다 뜨는지 / 처음에도 안 떴는지 (예전에 잰 적이 없는데도).
- [ ] **2-2. ‘10초 재기’ 값이 느낌과 맞는지**
  - 어떻게: [높이] → ‘내 목소리 재기’(또는 ‘내 목소리 다시 재기’) → ‘10초 재기’로 화면의 문장을 평소 목소리로 두세 번 읽는다.
  - 정상: 중앙값과 범위가 평소 말하는 느낌과 비슷하고, 다시 재도 크게 다르지 않다.
  - 이상하면 적을 것: 두세 번 잰 중앙값·범위 숫자와, 느낌과 어떻게 다른지 (예: 너무 낮게 나옴).
- [ ] **2-3. 작은 목소리**
  - 어떻게: 같은 문장을 작게(속삭임은 아니고 조용히) 읽어 ‘10초 재기’.
  - 정상: "목소리가 거의 잡히지 않았어요."가 너무 쉽게 뜨지 않고 값이 나온다.
  - 이상하면 적을 것: 뜬 문구, 그때 목소리 크기와 폰과의 거리(약 몇 cm).
- [ ] **2-4. 녹음 파일로 재기**
  - 어떻게: 재기 화면 → ‘녹음 파일로 재기’ → 음성 메모에서 ‘파일에 저장’해 둔 녹음을 고른다.
  - 정상: 파일을 읽어 중앙값·범위가 나온다.
  - 이상하면 적을 것: 나온 문구 (예: "이 파일을 읽지 못했어요"), 고른 파일의 길이.
- [ ] **2-5. 저장 뒤 기준 점선**
  - 어떻게: ‘이 값으로 저장’ → [높이] 그래프를 본다. 설정 → 디스플레이에서 어두운 모드로도 본다.
  - 정상: 보라 점선(기준)이 파란 띠(목표 범위)·분홍 꺾은선과 구분된다 (밝은·어두운 모드 둘 다).
  - 이상하면 적을 것: 어느 모드에서 무엇과 헷갈리는지.

## 3. [높이] 화면 (7분)

- [ ] **3-1. 작은 목소리에도 꺾은선이 이어지는지**
  - 어떻게: ‘반복 루프 재생’ → 문장을 작게, 그리고 보통으로 읽는다.
  - 정상: 작게 읽어도 꺾은선이 자주 끊기지 않는다 (쉬는 곳에서만 끊긴다).
  - 이상하면 적을 것: 작게 읽을 때 선이 어떻게 끊기는지(거의 안 그려짐·띄엄띄엄), 폰과의 거리.
- [ ] **3-2. 첫 화면에 문장 카드**
  - 어떻게: 정지한 상태에서 [높이] 탭 첫 화면을 스크롤하지 않고 본다.
  - 정상: 그래프 아래에 문장 카드와 ‘이전·다음’이 보인다 (요약 카드가 있으면 그만큼 아래로 밀린다).
  - 이상하면 적을 것: 무엇에 가려 안 보이는지. 기종(예: iPhone 15).
- [ ] **3-2a. 그래프 고정과 대본 읽기 모드** (2026-10-25 추가)
  - 어떻게: [높이] → 문장 종류를 ‘대본’으로 바꾸고, 그래프 아래를 위로 밀어 대본을 끝까지 읽는다. ‘내 문장’으로 돌아가 본다.
  - 정상: 그래프는 화면 위에 그대로 있고 아래만 넘어간다. ‘대본’일 때는 숫자가 한 줄로 작아지고 그래프가 낮아져 대본이 4줄 넘게 보인다. ‘내 문장’으로 돌아가면 원래 크기.
  - 이상하면 적을 것: 대본이 보이는 줄 수, 기종, 글자 크기 설정(설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기).
- [ ] **3-2b. 그래프 길이 = 들려줄 길이, 시작선** (2026-10-25 추가)
  - 어떻게: ‘들려줄 길이’를 1분으로 → ‘반복 루프 재생’ → 문장을 30초쯤 읽고, 그대로 1분 넘게 계속 읽는다. ‘지금 들어보기’ → 다 들은 뒤 다시 녹음되면 한 문장 읽고 ‘정지’.
  - 정상: 가로축이 1분이고 아래에 0:00·0:10… 시간이 있다. 오른쪽 끝이 늘 지금이고, 곡선과 시간·"시작" 실선이 함께 왼쪽으로 흐른다. 1분이 넘으면 "시작" 선이 왼쪽 밖으로 나간다. 듣는 동안에는 곡선이 멈추고 재생 위치 세로선이 그 위를 지나간다. 다시 녹음하면 "2번째" 점선이 생긴다.
  - 이상하면 적을 것: 곡선이 사라지는 때(몇 초에), 시간 글자가 겹치는지, 재생 위치 선과 소리가 어긋나는지(몇 초쯤).
- [ ] **3-2c. 3분 그래프가 버벅이지 않는지** (2026-10-25 추가)
  - 어떻게: ‘들려줄 길이’ 3분 → ‘반복 루프 재생’으로 3분 넘게 읽으며 곡선 움직임을 본다. 더 정확히 보려면 Mac에서 Xcode로 아이폰에 실행 → Debug 내비게이터(⌘7)의 CPU 그래프를 보거나, Product → Profile(⌘I) → ‘Animation Hitches’로 기록한다.
  - 정상: 곡선이 끊김 없이 부드럽게 흐르고, CPU가 꾸준히 낮다(대략 한 코어의 절반 아래). Hitches 기록에 빨간 막대가 거의 없다.
  - 이상하면 적을 것: 몇 분쯤부터 버벅이는지, 기종, CPU % 또는 Hitches 화면 캡처.
- [ ] **3-2f. 큰 그래프와 세로축 = 목표 범위 ±50 Hz** (2026-10-25 추가)
  - 어떻게: [높이] 화면을 ‘내 문장’과 ‘대본’으로 각각 본다. ‘반복 루프 재생’으로 목표 범위 안에서 말하다가, 일부러 목표보다 한참 높게(또는 낮게) "아—"를 낸다.
  - 정상: 그래프가 예전보다 크고, 세로축 숫자가 목표 범위 둘레만 보인다(예: 목표 135~175 Hz면 85~225 Hz). 목표에서 많이 벗어나 세로축 밖으로 나간 소리는 그래프 위·아래 끝에 붙은 회색 점선으로 그려지고, 큰 숫자에는 실제 Hz가 나온다. ‘내 문장’ 카드가 스크롤 없이 또는 조금만 내려서 보인다.
  - 이상하면 적을 것: 그래프가 너무 커서 문장·대본이 몇 줄 보이는지, 세로축 숫자, 끝에 붙은 점선이 헷갈리는지.
- [ ] **8-3. 녹음을 파일로 저장** (2026-10-25 추가)
  - 어떻게: 녹음 뒤 요약 카드의 ‘파일로 저장’ → 저장 창에서 ‘나의 iPhone’의 폴더를 골라 저장. [기록] → 남긴 녹음 → ‘파일로 저장’도 해 본다. 파일 앱에서 저장한 파일을 눌러 들어 본다.
  - 정상: "Ullim-날짜-시각.m4a" 이름으로 저장되고, 파일 앱에서 재생된다. 저장한 파일을 [높이]의 ‘녹음 불러오기’로 다시 열면 같은 곡선과 같은 요약 수치가 나온다. 같은 이름의 파일이 이미 있으면 iOS가 ‘대치 / 둘 다 유지’를 묻는다.
  - 이상하면 적을 것: 저장 창이 안 뜨는지, 저장 실패 안내, 파일 크기(3분 약 1.4MB 예상), 재생이 안 되는지.
- [ ] **3-2d. 음량 막대** (2026-10-25 추가)
  - 어떻게: ‘반복 루프 재생’ → 평소 크기로 한 문장, 작게 한 문장, 조금 크게 한 문장을 읽으며 그래프 아래 ‘음량’ 막대와 숫자(dBFS)를 본다. 폰과의 거리(약 30 cm)를 적어 둔다.
  - 정상: 크게 말할수록 막대가 길어진다. 평소 말할 때 3초 넘게 "소리가 꽤 커요…" 안내가 뜨지 않는다.
  - 이상하면 적을 것: 평소·작게·크게 말할 때의 dBFS 숫자(대략), 안내가 뜬 때. 이 숫자로 큰 소리 기준(지금 임시값 −10 dBFS, 3초)을 고친다.
- [ ] **3-2e. 공명 밝기 막대** (2026-10-25 추가)
  - 어떻게: [높이] → ‘조정’ → ‘내 목소리 다시 재기’ → ‘10초 재기’(결과에 "공명 밝기 기준(F2 중앙값)"이 나오는지 보고 저장). ‘반복 루프 재생’ → "이—"를 3초, "아—"를 3초 길게 낸 뒤, 기준 잴 때와 같은 문장("회의는 오후 두 시에 시작합니다.")을 평소처럼 읽는다.
  - 정상: "이"에서 점이 밝은 쪽(오른쪽), "아"에서 어두운 쪽(왼쪽)으로 간다. 같은 문장을 평소처럼 읽으면 가운데 보라 선 근처. 목소리를 높게 내면 점이 속이 빈 점(불확실)으로 바뀔 수 있다.
  - 이상하면 적을 것: 모음마다 점 위치(왼쪽·가운데·오른쪽), F2 숫자, 점이 자주 사라지는지.
- [ ] **3-3. ‘들려줄 길이’와 ‘조정’**
  - 어떻게: 정지한 상태에서 화면 아래 조작 영역의 ‘들려줄 길이’ 버튼을 눌러 바꿔 보고, 목표 범위 줄의 ‘조정’을 눌러 슬라이더를 펼쳤다 접는다.
  - 정상: 작은 창이 바로 뜨고 쓰기 편하다. ‘조정’을 펼치면 "목표 범위의 폭은 반음 n개예요."가 보인다.
  - 이상하면 적을 것: 불편한 점 (버튼이 작음, 창이 가림 등).
- [ ] **3-4. 목표 안·밖 구분 (색 말고도)**
  - 어떻게: 목표 범위 안팎을 오가게 높낮이를 바꿔 "아—"를 낸다.
  - 정상: 안은 굵은 분홍, 밖은 가는 회색으로 구분되고, 안일 때 숫자 아래에 "· 목표 범위 안"이 붙는다.
  - 이상하면 적을 것: 구분이 잘 안 되는 곳 (밝은 곳·어두운 모드 등).
- [ ] **3-5. 새 색 (밝은·어두운 모드)**
  - 어떻게: 밝은 모드와 어두운 모드에서 [높이] 화면 전체를 본다.
  - 정상: 분홍 꺾은선과 파란 띠가 잘 구분되고, 색이 너무 많아 보이지 않으며, 보라 ‘재기’ 버튼이 어색하지 않다.
  - 이상하면 적을 것: 어색한 색과 위치. 밝은 모드 분홍이 너무 붉어 보이면 그렇다고 적는다.
- [ ] **3-6. 반음 눈금**
  - 어떻게: 낮은 음과 높은 음에서 각각 같은 느낌의 폭으로 음을 오르내려 본다. ‘조정’에서 슬라이더를 낮은 쪽·높은 쪽에서 움직여 본다.
  - 정상: 낮은 쪽·높은 쪽 흔들림이 비슷한 크기로 그려지고, 슬라이더 손맛이 비슷하다. ‘반음 n개’ 숫자가 도움이 된다.
  - 이상하면 적을 것: 어느 쪽이 더 크게/작게 보이는지, 슬라이더가 튀는 높이 (낮은 쪽은 5 Hz 한 칸이 반음 1개 가까이라 크게 움직이는 것은 알려진 점).
- [ ] **3-7. 목표 범위를 멀리 옮겼을 때 안내**
  - 어떻게: ‘조정’에서 목표 범위를 기준보다 위로 멀리, 그다음 아래로 멀리 옮긴다. 끝나면 원래 값으로 되돌린다.
  - 정상: 위·아래 모두 같은 부드러운 안내("기준 목소리와 꽤 떨어진 범위예요…")가 뜬다.
  - 이상하면 적을 것: 한쪽에서만 뜨는지, 문구가 부담스러운지.
- [ ] **3-8. VoiceOver**
  - 어떻게: 설정 → 손쉬운 사용 → VoiceOver를 켜고(또는 측면 버튼 세 번) 그래프를 한 번 누른다. 끝나면 끈다.
  - 정상: "목소리 높이 그래프, 가로축 1분 … 녹음 시작부터 0:35, 목표 범위 …, 지금 … Hz"처럼 그래프 길이와 지난 시간을 읽는다. ‘조정’ 버튼에서는 슬라이더를 펼친다는 힌트를 읽는다.
  - 이상하면 적을 것: 읽은 문장 그대로, 또는 아무것도 안 읽었는지.
- [ ] **3-9. 문장 끝 (구절 목록)** (2026-10-26 추가)
  - 어떻게: ‘반복 루프 재생’으로 대본을 30초쯤 평소처럼 읽고 ‘지금 들어보기’ → 요약 카드의 "문장 끝 n개 중 …" 아래 ‘구절별로 보기’를 연다. 다시 들으면서 목록의 시간(0:03 등)과 실제 문장을 맞춰 본다. 마지막으로 ‘요약 복사’로 붙여 넣어 본다.
  - 정상: 쉼(0.25초 이상)마다 구절이 나뉘어 읽은 문장 수와 비슷하다. 질문 문장은 ‘올라감’, 끝을 크게 떨어뜨린 문장은 ‘내려감’·‘크게 내려감’. 붙여 넣은 글에 "문장 끝 (…)" 단락이 있다.
  - 이상하면 적을 것: 구절이 너무 잘게(단어마다) 또는 너무 크게(문장 여러 개) 나뉘는지, 끝을 일부러 끌어내렸는데 ‘안정’으로 나오는지, ‘긁혔을 수도 있어요’가 실제로 목이 긁힌 곳과 맞는지.

## 4. 반복 루프 재생 (5분)

- [ ] **4-1. 녹음 → 듣기 → 다시 녹음**
  - 어떻게: ‘반복 루프 재생’ → 문장을 읽고 ‘지금 들어보기’ → 다 들을 때까지 기다린다. 이것을 3번쯤 반복한다.
  - 정상: 들려준 뒤 1초쯤 쉬고 자동으로 다시 녹음된다. 들려주는 소리가 충분히 크다.
  - 이상하면 적을 것: 어느 단계에서 멈추거나 다음으로 안 넘어가는지.
- [ ] **4-2. 저절로 멈추지 않는지**
  - 어떻게: 4-1을 하는 동안 녹음 ↔ 듣기가 넘어갈 때마다 화면을 본다 (10번쯤).
  - 정상: 정지를 누르기 전에는 연습이 저절로 멈추지 않는다.
  - 이상하면 적을 것: 몇 번째 넘어갈 때 멈췄는지, 그때 블루투스·이어폰이 연결돼 있었는지.
- [ ] **4-3. 연습 중 말하는 언어 잠금**
  - 어떻게: 연습 중에 ‘말하는 언어’를 눌러 본다.
  - 정상: 연습 중에는 바꿀 수 없고, 정지한 뒤에는 바꿀 수 있다.
  - 이상하면 적을 것: 연습 중에 바뀌었는지.
- [ ] **4-4. 연습 기록 안내**
  - 어떻게: 30초 넘게(목소리 5초 넘게) 연습한 뒤 ‘정지’.
  - 정상: "연습 기록을 남겼어요 · …" 안내가 뜨고, [기록] 탭 ‘연습 기록’에 하나 생긴다.
  - 이상하면 적을 것: 안내가 안 떴는지, [기록]에 안 생겼는지, 연습한 시간.
- [ ] **4-5. 다 들은 뒤 바로 정지해도 방금 녹음이 남는지** (2026-10-30 고침)
  - 어떻게: 문장을 읽고 ‘지금 들어보기’ → 다 듣고 다음 녹음이 저절로 시작되면 **아무 말 없이** 바로 ‘정지’.
  - 정상: 요약 카드와 그래프가 방금 들은 녹음 그대로이고, "새 녹음에 목소리가 거의 없어서, 그 전 녹음을 마지막 녹음으로 두었어요."가 뜬다. 짧게라도(0.5초 넘게) 말한 뒤 정지하면 그 새 녹음이 남는다.
  - 이상하면 적을 것: 방금 녹음이 사라졌는지, 말했는데도 그 전 녹음이 남았는지(그때 목소리 크기·길이).

## 5. [모음] 모음 지도 (6분)

- [ ] **5-1. 실시간 모음 지도**
  - 어떻게: [모음] 탭 → ‘반복 루프 재생’ → 아·어·오·우·으·이·에를 2~3초씩 길게 낸다.
  - 정상: ‘이’는 왼쪽 위, ‘아’는 아래, ‘우’는 오른쪽 쪽으로 점이 간다.
  - 이상하면 적을 것: 어느 모음이 어디로 갔는지 (예: ‘오’와 ‘우’가 같은 곳).
- [ ] **5-2. 점의 흔들림과 점선 원**
  - 어떻게: 한 모음을 3초 고르게 낸다. 평소보다 높은 목소리로도 해 본다.
  - 정상: 점이 너무 크게 흔들리지 않는다. 높은 목소리에서 점선 원(F1 불확실)이 너무 자주도, 너무 드물게도 뜨지 않는다.
  - 이상하면 적을 것: 흔들림 정도, 점선 원이 뜬 모음과 높이.
- [ ] **5-3. 탭을 바꿔도 녹음이 이어지는지**
  - 어떻게: 연습 중에 [높이] ↔ [모음] 탭을 오간다.
  - 정상: 녹음이 끊기지 않고, 돌아오면 그래프와 지도가 이어서 그려진다.
  - 이상하면 적을 것: 끊긴 때와 화면.
- [ ] **5-4. 내 모음 지도 재기**
  - 어떻게: ‘내 모음 지도’에서 모음을 고르고 ‘재기 · 3초’로 7개를 하나씩 잰다. ‘아’를 두세 번 다시 잰다.
  - 정상: 지도 배치가 5-1과 비슷하게 그럴듯하고, 같은 모음을 다시 재면 값이 비슷하다 (흔들린 범위 십자가 너무 크지 않다).
  - 이상하면 적을 것: 이상한 모음과 그 F1·F2 숫자, 다시 잴 때 얼마나 달라졌는지.
- [ ] **5-5. 비교 숫자**
  - 어떻게: 내 모음 지도에서 모음 하나를 고른 채 연습하며 그 모음을 다시 낸다.
  - 정상: 비교 숫자가 0 근처로 온다.
  - 이상하면 적을 것: 나온 숫자.
- [ ] **5-6. 파일로 재기**
  - 어떻게: 모음 하나를 고르고 ‘파일로’ → 음성 메모에서 그 모음을 길게 낸 녹음을 고른다.
  - 정상: 그 모음이 지도에 저장된다.
  - 이상하면 적을 것: 나온 문구.

## 6. [기록]·두 녹음 비교 (9분)

- [ ] **6-1. 남긴 녹음의 메모**
  - 어떻게: [높이]에서 녹음 뒤 요약 카드의 ‘기록에 남기기’를 두 번(두 녹음) 누른다. [기록] → 남긴 녹음 하나 → 메모를 한글로 고치고 뒤로 갔다가 다시 들어간다.
  - 정상: 고친 메모가 남아 있다.
  - 이상하면 적을 것: 메모가 사라졌는지, 한글이 깨졌는지.
- [ ] **6-2. 다시 듣고 곡선 보기**
  - 어떻게: 남긴 녹음 → ‘다시 듣고 곡선 보기’.
  - 정상: [높이] 탭으로 가서 소리와 곡선이 함께 나온다.
  - 이상하면 적을 것: 소리만 나는지, 곡선만 나오는지.
- [ ] **6-3. 어두운 모드의 [기록]**
  - 어떻게: 어두운 모드에서 [기록] 탭의 그래프와 목록을 본다.
  - 정상: 점·띠·막대·글자가 잘 보인다.
  - 이상하면 적을 것: 잘 안 보이는 것.
- [ ] **6-4. 두 녹음 비교: 듣기**
  - 어떻게: [기록] → ‘두 녹음 나란히 비교’ → ‘A 듣기’, ‘B 듣기’, ‘A → B 이어 듣기’.
  - 정상: 스피커로 충분히 크게 들리고, 이어 듣기가 비교에 도움이 된다.
  - 이상하면 적을 것: 소리가 작은지, 이어 듣기가 길거나 쓸모없게 느껴지는지.

- [ ] **6-5. 녹음 → 재기 → 저장 연속 흐름** (2026-10-25 고친 버그 확인)
  - 어떻게: [높이]에서 ‘반복 루프 재생’으로 문장을 읽고 ‘지금 들어보기’ → 다 들으면 ‘정지’. 요약 카드의 중앙값을 적어 둔다. 이어서 ‘내 목소리 다시 재기’ → ‘10초 재기’로 일부러 다른 높이(조금 높게 또는 낮게)로 읽고 ‘닫기’. [높이]로 돌아와 요약 카드를 다시 보고 ‘기록에 남기기’ → [기록]에서 그 녹음을 연다. 마지막으로 [기록]에서 그 녹음을 밀어서 지우고 [높이]로 돌아온다.
  - 정상: 재기 뒤에도 요약 카드의 숫자와 그래프가 처음 녹음 그대로이고, [기록]에 남은 녹음의 중앙값도 같다. 지운 뒤 [높이]의 버튼이 다시 ‘기록에 남기기’로 돌아온다.
  - 이상하면 적을 것: 재기 뒤 바뀐 숫자(전·후), [기록]의 숫자, 지운 뒤 버튼 글자.
- [ ] **6-6. 녹음마다 분석 로그**
  - 어떻게: ‘반복 루프 재생’ → 문장을 읽고 ‘지금 들어보기’를 3번쯤 반복(전체 30초 넘게) → ‘정지’. [기록] → ‘연습 기록’의 맨 위 줄을 누른다. ‘요약 복사’를 눌러 메모 앱에 붙여 넣어 보고, ‘AI에게 피드백 받기’로 공유 창을 연다(보내지 않고 닫아도 된다).
  - 정상: ‘녹음마다’에 들어보기를 누른 횟수만큼 줄이 있고, 각 줄의 중앙값이 그때 요약 카드에서 본 숫자와 같다. 붙여 넣은 글에 연습 전체와 녹음마다의 숫자가 있고, 공유 창에 ChatGPT·Claude가 뜬다.
  - 이상하면 적을 것: 줄 수(들어보기 횟수와 다른지), 카드와 다른 숫자, 공유 창에 뜬 앱.
- [ ] **6-7. 기록에 남은 문장 끝** (2026-10-30 추가)
  - 어떻게: 6-6처럼 문장을 읽고 ‘지금 들어보기’를 몇 번 한 뒤 정지한다. 들을 때마다 요약 카드의 문장 끝 한 줄(“문장 끝 N개 중 M개가 …”)을 적어 둔다. [기록] → 그 연습 기록, 그리고 ‘기록에 남기기’로 남긴 녹음 하나를 연다.
  - 정상: 연습 기록의 ‘녹음마다’ 각 줄 아래에 그때 카드와 같은 문장 끝 숫자가 있고, 위쪽 ‘문장 끝’ 칸은 그 녹음들을 더한 수다. 남긴 녹음에도 ‘문장 끝’ 칸이 있다. 이 기능 전에 남긴 기록에는 ‘문장 끝’ 칸이 없다. 요청문(‘요약 복사’)에 녹음마다 문장 끝과 ‘문장 끝 (녹음 N개를 합쳐서, …)’ 단락이 있다.
  - 이상하면 적을 것: 카드와 다른 숫자, 칸이 안 보이는 기록, 예전 기록이 열리지 않거나 사라졌는지.

- [ ] **6-8. 공명 밝기 추이** (2026-10-31 추가)
  - 어떻게: 내 목소리 재기를 한 번 하고(기준 F2가 생김), 같은 대본으로 며칠 연습한다. [기록] → 높이 그래프 아래 ‘연습마다 공명 밝기 (F2, Hz)’.
  - 정상: 연습마다 분홍 점이 하나씩 있고 보라 점선(지금 기준)이 있다. 같은 대본을 읽은 연습끼리는 점이 비슷한 높이다. 2026-10-25 전의 연습은 점이 없고, 기간 안에 공명 기록이 하나도 없으면 안내 한 줄만 나온다.
  - 이상하면 적을 것: 같은 대본인데 점이 얼마나 들쭉날쭉한지(Hz), [높이] 공명 막대의 느낌(밝은·어두운)과 그래프가 맞는지, 눈금 글자가 겹치는지.

## 7. 연습 알림 (3분)

- [ ] **7-1. 스위치**
  - 어떻게: [기록] → 오른쪽 위 종 → ‘매일 연습 알림’ 스위치를 손가락으로 한 번 누른다.
  - 정상: 한 번 누르면 켜진다 (시뮬레이터에서는 끌어야 켜졌다).
  - 이상하면 적을 것: 누르기로 안 켜지는지.
- [ ] **7-2. 알림 권한**
  - 어떻게: 처음 켤 때 뜨는 권한 창을 본다.
  - 정상: 알림 권한을 묻고, 창에 앱 이름이 "울림"으로 나온다. 허용하면 시간 고르기가 보인다.
  - 이상하면 적을 것: 권한 창이 안 떴는지, 이름.
- [ ] **7-3. 알림 문구**
  - 어떻게: 화면의 설명과 (나중에 받으면) 알림 문구를 읽는다.
  - 정상: 부담스럽지 않다 (압박·점수·연속 기록 같은 말이 없다).
  - 이상하면 적을 것: 부담스러운 문장 그대로.

## 8. 공유·음성 메모 열기 (4분)

- [ ] **8-1. 요약 글만 보내기**
  - 어떻게: [높이] 요약 카드 → ‘AI에게 피드백 받기’ → ‘요약 글만 보내기’.
  - 정상: 공유 창에 ChatGPT·Claude가 뜬다 (‘녹음 파일과 함께’일 때는 안 뜨는 것이 알려진 점).
  - 이상하면 적을 것: 공유 창에 뜬 앱 목록 (‘더 보기’ 포함).
- [ ] **8-2. 음성 메모에서 울림으로 열기**
  - 어떻게: 음성 메모 앱 → 녹음 하나 → 공유 → 울림.
  - 정상: 공유 창에 "울림"이 뜨고, 누르면 울림이 열리며 바로 재생되고 곡선이 그려진다.
  - 이상하면 적을 것: 공유 창에 울림이 없는지, 열리기만 하고 재생이 안 되는지.

## 따로: 시간이 걸리는 항목

- [ ] **A. 3분 녹음** (약 5분)
  - 어떻게: ‘들려줄 길이’를 3분으로 → ‘반복 루프 재생’ → 4분 넘게 말한 뒤 ‘지금 들어보기’.
  - 정상: 마지막 3분만 들린다. 다 들으면 자동으로 다시 녹음된다.
  - 이상하면 적을 것: 들린 길이, 앱이 멈추거나 느려졌는지.
- [ ] **B. 며칠 연습한 뒤 [기록] 그래프** (며칠)
  - 어떻게: 며칠 연습한 뒤 [기록] 탭의 ‘연습마다 높이’ 그래프를 7일·30일로 본다.
  - 정상: 점이 많아도 겹쳐서 읽기 어렵지 않다.
  - 이상하면 적을 것: 읽기 어려운 기간, 캡처.
- [ ] **C. 며칠 간격 두 녹음 비교** (며칠)
  - 어떻게: 같은 문장을 며칠 간격으로 ‘기록에 남기기’ → ‘두 녹음 나란히 비교’.
  - 정상: 높이 분포 그래프가 두 녹음의 차이를 잘 보여 준다.
  - 이상하면 적을 것: 차이가 느낌과 다르게 그려지는 점.
- [ ] **D. 알림이 정한 시간에 오는지** (연습하지 않은 날)
  - 어떻게: 연습하지 않은 날, 알림 시간을 몇 분 뒤로 정하고 앱을 닫은 뒤 잠금 화면을 본다.
  - 정상: 정한 시간에 잠금 화면에 알림이 온다 (앱을 켜 둔 동안에는 뜨지 않는 것이 정상).
  - 이상하면 적을 것: 안 왔는지, 늦게 왔는지(몇 분).
- [ ] **E. 연습한 날은 알림이 오지 않는지** (연습한 날)
  - 어떻게: 알림 시간 전에 30초 넘게 연습하고 정지한다.
  - 정상: 그날은 알림이 오지 않고, 다음 날은 온다.
  - 이상하면 적을 것: 연습했는데 온 날짜와 연습한 시간.
