# 웹(PWA)·안드로이드(APK) 계획 (2026-10-25 정함)

웹 버전을 먼저 만들고, 같은 웹 코드를 Capacitor로 감싸 안드로이드 APK를 만든다 (Kotlin으로 따로 짜지 않는다).
2026-10-25 사용자 결정: **웹을 먼저** 진행하고, A1(APK 시험판, JDK·안드로이드 SDK 설치)은 나중에 한다. 순서는 W3 → W4 → W5 → A1 → A2.
스토어 없이 APK 파일을 폰에 직접 설치한다. 첫 범위는 [높이] 탭이다. [모음]·[기록]은 그다음 계획에서 정한다.

## 정한 것
- 위치: 이 저장소의 `web/`. 대본(`VoicePractice/Models/PracticeScripts.json`)은 iOS와 한 파일을 같이 쓴다 (W3).
- 도구: Vite + TypeScript + Svelte 5 + Vitest (+ svelte-check). PWA는 vite-plugin-pwa (W5), APK는 Capacitor 8 (A1).
  - 패키지는 정확한 버전으로 고정하고, 나온 지 2주가 지난 버전을 쓴다 (공급망 사고를 피하려고).
- APK 앱 ID: `io.github.chae_rini.ullim` (실명 없음, 설치한 뒤에는 바꿀 수 없음). 서명 키는 깃에 올리지 않는다.
- GitHub Pages 공개는 W5에서 따로 묻는다.

## iOS와 다른 점 (미리 정한 것)
- 파일로 저장: 웹은 WAV (브라우저마다 m4a 만들기가 달라서). 3분이면 약 17 MB. 이 기기에 내려받기로 저장한다.
- AI에게 피드백 받기: 브라우저 공유 창(Web Share)으로. 공유 창이 없는 브라우저(컴퓨터의 일부)는 요청문을 복사하고 알린다.
- ‘기록에 남기기’와 ‘말하는 언어’는 웹에 [기록]이 생길 때 더한다 (W4에는 없음).
- 반복 루프 동안 마이크는 켜 둔 채, 듣는 동안 들어오는 소리는 분석하지 않는다 (iOS는 단계마다 녹음 장치를 새로 만든다).
- 연습 알림: 웹은 넣지 않는다 (앱을 닫았을 때 알림을 보내려면 서버가 필요해 원칙 2와 부딪힌다). APK는 나중에 로컬 알림 플러그인으로.
- 아이폰 사파리는 자동 음량 조절을 끄지 못할 수 있다 → 꺼졌는지 확인해 화면에 알린다.
- 폰 브라우저의 마이크는 HTTPS에서만 켜진다 → 폰 확인은 APK 또는 GitHub Pages로.

## 직접 확인할 것 (Claude의 미리보기 브라우저는 마이크를 막아서 실제 목소리는 사용자가 확인한다)
- [ ] **W2. 컴퓨터 브라우저에서 마이크로 높이 재기** (약 5분)
  - 어떻게: 저장소 맨 위에서 `npm --prefix web run dev` → Chrome이나 Safari로 http://localhost:5173 → ‘마이크로 재기’ → 마이크 허용 → "아—"를 3초쯤 길게, 높게·낮게 바꿔 가며. 같은 소리를 아이폰 울림 [높이]로도 재 본다.
  - 정상: 말하는 동안 Hz 숫자가 바뀌고 아이폰과 비슷하다(몇 Hz 안). 조용하면 "–". ‘자동 음량 조절·잡음 제거·에코 제거: 꺼짐’. 음량은 말할 때 대략 −40~−15 dBFS.
  - 이상하면 적을 것: 브라우저 이름, 처리 상태 세 줄, 표본화 주파수, 아이폰과 몇 Hz 차이 나는지, 숫자가 늦게 따라오는지.
- [ ] **W3. [높이] 화면을 휴대폰 크기로 써 보기** (약 10분, W2와 함께)
  - 어떻게: 위와 같이 개발 서버를 열고, 브라우저 창을 휴대폰 폭으로 줄이거나(개발자 도구의 기기 모드) 그대로 본다. 처음 열면 뜨는 ‘내 목소리 재기’로 10초 재고 저장 → ‘마이크 켜기’로 말하면서 그래프를 본다. 문장 종류를 ‘대본’으로 바꿔 읽어 본다.
  - 정상: 기준을 저장하면 목표 범위(기준 ±20 Hz)와 보라 ‘기준’ 점선이 생기고, 세로축이 목표 ±50 Hz로 좁아진다. 말하면 오른쪽 끝에서 곡선이 나오며 왼쪽으로 흐르고, 목표 안은 굵은 분홍. 음량·공명 막대가 움직인다. 대본을 고르면 그래프가 낮아지고 대본이 6줄 안팎 보인다. 새로 고쳐도 목표 범위·기준·들려줄 길이·문장 종류가 남아 있다.
  - 이상하면 적을 것: 브라우저·창 크기, 곡선이 늦게 따라오는지·끊기는지, 아이폰 앱과 다른 점.
- [ ] **W4. 반복 루프·불러오기·요약 카드** (약 10분)
  - 어떻게: ‘반복 루프 재생’ → 한 문장 읽기 → ‘지금 들어보기’ → 다 들으면 1초 뒤 ‘2번째’ 녹음이 저절로 시작되는지 → 한 번 더 듣고 ‘정지’. 요약 카드의 ‘파일로 저장’, ‘요약 복사’, ‘AI에게 피드백 받기’(요약 글만 / 녹음 파일과 함께)를 눌러 본다. 📁로 음성 메모 파일을 불러온다.
  - 정상: 들려주는 소리가 방금 읽은 목소리이고 잘 들린다(가장 큰 순간이 약 −1 dBFS가 되게 키움). 들을 때 그래프의 재생 위치 선이 움직이고 뒷부분은 흐리다. 저장한 WAV를 다시 불러오면 같은 수치가 나온다. 공유 창이 없는 브라우저에서는 "요약을 복사했어요" 안내.
  - 이상하면 적을 것: 들려주는 소리가 작거나 끊기는지, 듣는 동안 마이크가 스피커 소리를 다시 잡는지(그래프가 움직이면 이상), 브라우저 이름.
  - 아이폰 사파리에서는 W5(GitHub Pages)에 올린 뒤 확인한다 — 마이크를 켜 둔 채 재생하면 소리가 작게 들릴 수 있어서 꼭 볼 것.
